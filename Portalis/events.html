Format guide (how to write an event)

Start each event with Event: and leave a blank line between events. Everything is checked before it is saved.

LineWhat to writeExamples
Event:The name (required)Intramurals Opening
Date:One day or a range (required)Nov 20, 2026  ·  Dec 1-5, 2026  ·  2026-11-20
Time:Start, or start - end. Leave out or write All day.8:00 AM - 5:00 PM  ·  1pm  ·  All day
Place:Where (optional)School gym
Details:Notes for the class (optional, can use several lines)Wear your PE uniform.
