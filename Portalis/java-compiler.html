Java compiler

Paste any Java program and run it - the class name doesn't matter. Type your answers right in the terminal.

Code is sent to Judge0 Community Edition (Java 17) to compile and run. Because Judge0 can't pause a running program, Portalis re-runs your program with each answer you type and shows it as one live session. This is why random numbers and the current time can look different after every answer.
