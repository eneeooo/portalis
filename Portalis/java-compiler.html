Java compiler

Paste any Java program and run it. Type your answers right in the terminal.

Your code is compiled and run by Judge0 Community Edition (Java 17).

Judge0 can't pause a running program, so Portalis re-runs your program with every answer you type and shows it as one live session. That is why random numbers and the current time can look different after each answer.

Any class name works, so you can paste code without changing it.
