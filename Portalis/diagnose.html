Still stuck?

Open the student login address in a new tab and read the message:

  • Requested function was not found: deploy username-login from the current repository.
  • Missing authorization header or Invalid JWT: JWT verification is still on. Turn it off.
  • {"error":"Method not allowed."}: the function is fine. Run the checks again.
  • The page does not load at all: the project is paused or the address in config.js is wrong.
